Reglas del programa

  • Cada servicio y cada tipo de membresía otorga una cantidad fija de puntos (entero, 0 o mayor). Con 0 no otorga puntos.
  • No otorgan puntos el consumo de una membresía, las cortesías, los servicios gratuitos ni las redenciones.
  • Cambiar los puntos de un servicio o de una membresía no modifica los puntos ya acumulados.
  • Al pedir un canje sus puntos quedan reservados, empezando por los que vencen antes; se descuentan al entregarlo y vuelven si se rechaza, se cancela o vence (los que ya vencieron no vuelven a estar disponibles).
